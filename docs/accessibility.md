# MindCare NER — Accessibility & Elderly-First Universal Design

**Standard:** WCAG 2.2 Level AA / AAA Compliant Design  
**Target Demographic:** Elderly users aged 65–90 with Mild Cognitive Impairment (MCI) and early dementia.

---

## 1. Supported Accessibility Modes

### 1. `STANDARD` Mode
- Refined high-contrast teal (`#006767`) on soft off-white (`#f8f9ff`) canvas.
- Crisp typography (minimum 16px body text) with generous 44px+ touch targets.

### 2. `LARGE_TEXT` Mode
- Increases global font scale by 25% (18px base, 24px headings, 20px buttons).
- Generous line height (1.6 to 1.8) preventing optical text crowding.

### 3. `HIGH_CONTRAST` Mode
- Pure high-contrast palette: **Vibrant Sunflower Yellow (`#fde047`) on Pitch Black (`#000000`) canvas**.
- Exceeds WCAG 2.2 AAA contrast ratio (> 12:1).
- Disables subtle pastel gradients in favor of sharp 2px solid boundary borders.

### 4. `VOICE_FIRST` Mode
- Prioritizes automated spoken audio guidance for all instructions and reminders.
- Expands microphone voice assistant triggers across all primary screens.
- Synthesizes auditory confirmation chimes for all button taps.

### 5. `REDUCED_MOTION` Mode
- Disables all CSS transform animations, spring physics, and continuous pulse effects.
- Prevents visual disorientation or dizziness in elderly individuals.

### 6. `LOW_LITERACY` Mode
- Replaces dense text descriptions with high-recognition visual iconography, color-coded badges, and native voice audio clips.

3. **Bengali / বাংলা (bn)**
4. **Manipuri / মৈতৈলোন্ (mni)**
5. **Mizo / Lushai (lus)**
6. **Khasi / Ka Ktien Khasi (kha)**
7. **Hindi / हिन्दी (hi)**
