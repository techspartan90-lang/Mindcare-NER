# MindCare NER — Known Limitations & System Boundaries

## 1. Medical & Clinical Scope
- **Non-Diagnostic Aid:** MindCare NER is not an FDA/CDSCO-cleared medical device. It does not cure, prevent, mitigate, or reverse dementia, Alzheimer's disease, or neurodegenerative conditions.
- **Supportive Lifestyle Tool:** Telemetry metrics represent activity adherence and interaction latency, not formal diagnostic MoCA/MMSE clinical scores.

---

## 2. Browser & Hardware Scope
- **WebGL Context Loss:** If WebGL loses context, the application automatically switches to 2D Mode without crashing.
- **Microphone Permissions:** Browser audio recording requires explicit user approval on HTTPS connections.
