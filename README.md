# MindCare NER — AI-Assisted Cognitive Care Ecosystem

> **"Remember. Engage. Connect."**  
> An AI-enabled personalized cognitive assistance and longitudinal monitoring platform designed to support cognitive engagement, daily functioning, and caregiver support for elderly seniors across North East India.

---

## 🌟 Overview

**MindCare NER** is a culturally rooted, clinically calibrated, and offline-first digital healthcare platform designed specifically for the unique geographic, linguistic, and cultural landscape of the 8 North Eastern states of India (Assam, Meghalaya, Manipur, Mizoram, Nagaland, Tripura, Arunachal Pradesh, and Sikkim).

---

## 🚀 Key Features

- **🌐 3D Interactive Central Nexus:** High-performance WebGL/Canvas spatial visualization connecting 9 core health pillars (Cognitive Activities, Daily Routine, Memory Garden, Family Connect, Caregiver Portal, Clinician Telemetry, AI Personalization, Multilingual Voice, and Security Vault).
- **🧠 Culturally Anchored Cognitive Games:** Six MoCA-calibrated cognitive exercises incorporating regional heritage (Assam tea sorting, Bihu dhol rhythm matching, Khasi spice recall, and Mizo textile sequences).
- **🗣️ 7 Regional Dialects & Speech AI:** Native voice interaction supporting Assamese, Bengali, Bodo, Khasi, Meiteilon, Mizo, Hindi, and English.
- **⚡ 100% Offline-First Edge Sync:** On-device encrypted SQLite database resilient to monsoonal blackouts and hill cellular outages.
- **👨‍👩‍👧 Family Connect & Peace-of-Mind Telemetry:** One-touch voice messaging, speed-dial calling, and real-time routine compliance tracking for working caregivers.
- **🩺 Clinician Analytics Dome:** Longitudinal MoCA/MMSE-aligned stability trajectories, response latency drift metrics, and FHIR/ABDM compliant summary exports.
- **🔒 Privacy & DPDP Compliance:** Full compliance with the Indian Digital Personal Data Protection (DPDP) Act 2023 and AES-256 encrypted local vaults.
- **♿ WCAG 2.2 AAA Accessibility:** 64px+ tactile touch targets, high-contrast dark theme (`#07111F` / `#101F31` / `#19C3B1`), font magnification, and tremor compensation.

---

## 🛠️ Technology Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Three.js, GSAP, Motion, Recharts, Lucide Icons.
- **Backend:** Node.js Express, TypeScript, SQLite (`better-sqlite3` / node sqlite), REST API.
- **Audio Engine:** Web Audio API procedural synthesizer & Web Speech API.

## 📦 Quick Start & Installation

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### 1. Clone & Install
```bash
git clone https://github.com/guruprasanth4059-alt/Mindcare-NER.git
cd Mindcare-NER
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
npm start
```
